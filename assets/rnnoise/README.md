# RNNoise model

`somnolent-hogwash.rnnn` is the `sh.rnnn` model from
[GregorR/rnnoise-models](https://github.com/GregorR/rnnoise-models/tree/master/somnolent-hogwash-2018-09-01).
It is an `rnnoise-nu model file version 1` model compatible with FFmpeg's
`arnndn` filter and is intended to separate speech from typical recording
noise.

The model is bundled locally so preprocessing does not require a network
connection.
